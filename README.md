# Personal Portfolio

Personal portfolio website, redesigned using Claude Code and agentic development.

## Stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript + Tailwind CSS
- Deploy: [Vercel](https://vercel.com)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Development

This project uses Claude Code for agentic development. See [`CLAUDE.md`](./CLAUDE.md) for project context and conventions, and `.claude/skills/` for project-specific skills.
